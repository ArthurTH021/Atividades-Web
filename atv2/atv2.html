Como foi resolvido:

Foram utilizados campos de input para inserir as notas. Ao clicar em "Calcular", a função JavaScript lê os valores, converte para número com parseFloat, calcula a média e verifica a situação do aluno com if/else. O resultado é exibido usando textContent. Também foi adicionado um botão "Resetar" para limpar os campos e o resultado.
