Atividade 19 - Editor de Texto Simples

O site foi desenvolvido como um editor de texto simples utilizando HTML, CSS e JavaScript. O HTML estrutura a interface com botões para aplicar formatações (negrito, itálico e sublinhado) e uma área de texto editável. O CSS estiliza o layout com um visual limpo e moderno, destacando os botões e delimitando a área de edição com bordas e cores contrastantes. O JavaScript implementa a funcionalidade dos botões usando o comando execCommand, permitindo ao usuário formatar o texto selecionado com facilidade. O resultado é uma ferramenta prática e intuitiva para editar textos diretamente no navegador.
