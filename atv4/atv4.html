A lógica de conversão é baseada nas seguintes fórmulas:

  • Celsius para Fahrenheit: F = C × 1.8 + 32
  • Fahrenheit para Celsius: C = (F - 32) ÷ 1.8

    • O JavaScript é utilizado para capturar os valores inseridos, realizar o cálculo com base na escolha do usuário e mostrar o resultado na tela.
