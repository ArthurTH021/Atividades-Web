Atividade 20 - Jogo de Memória

Data de resolução: 27/05/2025

Enunciado

Implemente um jogo da memória simples com cartas viradas para baixo. Ao clicar em duas cartas, elas devem virar para cima. Se forem iguais, permanecem visíveis; se não, viram para baixo novamente. O jogo termina quando todas as cartas forem encontradas.

Resolução

Explicação

Defini um array com pares de emojis e embaralho esse array sempre que o tabuleiro é criado. Para cada carta, crio um elemento div e adiciono um evento de clique que controla a lógica do jogo: ao clicar, a carta é revelada, se duas cartas forem abertas, ele verifica se são iguais. Se forem, marca como "matched", se não, vira ambas para baixo após um pequeno atraso. Coloquei um botão de "Recomeçar", que reinicializa o tabuleiro e embaralha as cartas novamente. O código garante que o usuário só pode interagir com duas cartas por vez e exibe uma mensagem quando todas as cartas forem encontradas.
