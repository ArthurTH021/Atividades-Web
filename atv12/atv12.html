Atividade 12

1. Qual a capital do Brasil?



2. Qual é o resultado de 5 + 3?



3. Qual linguagem usamos no navegador?



4. Qual o maior planeta do sistema solar?



5. Qual cor resulta da mistura de azul com amarelo?



O site foi feito como um quiz interativo utilizando HTML, CSS e JavaScript. O HTML estrutura o formulário com cinco perguntas de múltipla escolha, cada uma com três alternativas. O CSS personaliza o visual da página, aplicando cores contrastantes, bordas arredondadas e espaçamento adequado para facilitar a leitura. O JavaScript contém a lógica de verificação: ao clicar no botão “Ver Resultado”, o script contabiliza quantas respostas corretas o usuário marcou e exibe a pontuação final. Essa combinação torna o site funcional, visualmente atrativo e ideal para testar conhecimentos de forma simples.
