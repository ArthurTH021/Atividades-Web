Cronômetro

00:00

O site foi feito como um cronômetro digital utilizando HTML, CSS e JavaScript. O HTML define a estrutura com um título, um visor para o tempo e três botões: iniciar, pausar e resetar. O CSS estiliza o layout de forma simples e centrada, com botões destacados em vermelho para facilitar a interação. O JavaScript implementa a lógica do cronômetro, contando os segundos e atualizando o visor a cada segundo, além de permitir pausar ou reiniciar o tempo. Essa combinação torna o site funcional, intuitivo e visualmente claro para acompanhar a contagem do tempo.
