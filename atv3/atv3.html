Atividade 3

O projeto da Tabuada Interativa usa HTML para criar a estrutura da página, com um campo de número, um botão e uma área de resultado. Em JavaScript, usamos querySelector para acessar os elementos, addEventListener para reagir ao clique do botão e um laço for para gerar a tabuada de 1 a 10. O resultado é exibido na tela com innerHTML, mostrando como manipular o DOM de forma dinâmica.
