Atividade 9

O site foi feito como uma lista de compras interativa, usando HTML, CSS e JavaScript. O HTML define a estrutura com campos para o usuário inserir o nome do item e a quantidade, além de um botão para adicionar os itens. O CSS estiliza a página com cores suaves, botões personalizados e um layout centralizado e organizado. O JavaScript é responsável pela lógica: ele capta os valores digitados, cria elementos HTML dinamicamente para exibir cada item com sua quantidade, e inclui um botão "Remover" que permite excluir o item da lista, tornando o site funcional e fácil de usar.
