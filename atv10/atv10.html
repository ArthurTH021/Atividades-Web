Sorteador de Nomes

Como foi resolvido:

Foi criado um campo textarea onde o usuário insere vários nomes separados por vírgula. A função em JavaScript lê esses nomes, transforma em um array usando split(',') e remove espaços usando trim(). O sorteio é feito com Math.random() para escolher um índice aleatório do array. O nome sorteado é exibido na tela. Também há um botão "Resetar" que limpa os campos e o resultado.
