Atividade 7

Digite um número de 1 a 100:


O site foi desenvolvido como um jogo de adivinhação utilizando HTML, CSS e JavaScript. O HTML define a estrutura básica da página, incluindo um campo para o usuário digitar um número e um botão para enviar o palpite. O CSS estiliza a interface com centralização, bordas arredondadas e cores vivas, oferecendo uma aparência limpa e agradável. Já o JavaScript implementa a lógica do jogo: um número aleatório entre 1 e 100 é gerado, e o usuário deve tentar adivinhá-lo. A cada tentativa, o site informa se o número é maior ou menor, até o acerto, exibindo o total de tentativas.
