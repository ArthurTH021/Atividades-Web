Atividade 6

    O site foi desenvolvido como uma lista de tarefas interativa (To-Do List) utilizando HTML, CSS e JavaScript. O HTML estrutura a página com campos para inserir tarefas e uma lista para exibi-las. O CSS estiliza o visual com cores suaves, botões arredondados e destaque para tarefas concluídas. O JavaScript adiciona a funcionalidade principal: ao clicar no botão "ADD", a tarefa digitada é inserida na lista com botões para "concluir" (que risca a tarefa) e "remover" (que a exclui da lista), tornando o site dinâmico e funcional.
