Atividade 13

O site foi desenvolvido como um jogo da velha utilizando HTML, CSS e JavaScript. O HTML estrutura o tabuleiro com nove células dispostas em três linhas e três colunas, além de botões e área para exibir mensagens. O CSS define um visual limpo e organizado, com cores suaves, bordas arredondadas e efeitos ao passar o mouse. Já o JavaScript implementa a lógica do jogo: alternância entre os jogadores "X" e "O", verificação de vitória ou empate a cada jogada, e um botão para reiniciar a partida. Isso torna o jogo totalmente funcional, interativo e de fácil uso.
