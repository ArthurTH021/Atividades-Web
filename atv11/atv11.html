Atividade 11

Explicação

Utilizamos JavaScript para receber o valor digitado, e com o auxílio de laços de repetição e operadores matemáticos, o sistema verifica quantas notas de cada valor são necessárias para compor o total solicitado, começando pelas notas de maior valor.

A cada iteração, usamos Math.floor() e o operador módulo (%) para calcular a quantidade de cada cédula. Só são utilizadas as notas disponíveis (100, 50, 20, 10, 5, 2).
