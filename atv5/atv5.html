Insira o seu cpf e veja se ele está regular

Este site foi desenvolvido com uma estrutura simples em HTML para permitir que o usuário insira um número de CPF e verifique se ele é válido com base no comprimento do número (deve ter exatamente 11 dígitos). O estilo visual foi aplicado com CSS, utilizando cores neutras e destaque em vermelho para os elementos importantes, além de uma formatação moderna com bordas arredondadas e sombras. A validação é feita por um pequeno script JavaScript que analisa o tamanho do CPF informado e exibe uma mensagem de "Regular!" em verde se válido, ou "CPF Incorreto!" em vermelho se inválido, proporcionando uma interação rápida e clara para o usuário.
